# YOLO网页检测系统

这是一个基于Flask开发的简易网页应用，用于枸杞成熟度检测。

## 功能特点

- 选择YOLO的`.pt`模型文件
- 上传待检测图片
- 在主界面点击按钮开始检测
- 在图片中绘制检测框和置信度
- 统计成熟果数量和果实总数量
- 计算成熟果占比
- 输出采摘建议

## 决策规则

- 未识别到成熟枸杞时：当前区域不采摘
- 成熟果实数量低于5个且占比高于0.65时：成熟果实较少但成熟度高，建议精准采摘
- 成熟果实数量低于5个且占比低于0.65时：低优先级区域，可局部精准采摘或暂缓采摘
- 成熟果实数量大于等于5个且占比高于0.65时：成熟果实充足，建议常规区域采摘
- 成熟果实数量大于等于5个但占比低于0.65时：成熟果实数量足够但占比偏低，建议结合聚集程度判断

## 文件说明

- `app.py`：Flask后端程序和YOLO模型推理代码
- `templates/index.html`：网页页面结构文件
- `static/style.css`：网页样式文件
- `requirements.txt`：项目依赖文件

## 运行方法

```bash
cd X:\XXX\web_app
pip install -r requirements.txt
python app.py
```

运行后，在浏览器中打开以下地址：

```text
http://127.0.0.1:5000
```

## 类别名称说明

程序将以下标签识别为成熟果：

- `ripe`

程序将以下标签识别为未成熟果：

- `unripe`

如果你的模型使用了不同的类别名称，请在`app.py`中修改`DetectionItem.is_mature`的判断规则。
